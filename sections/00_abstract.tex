\begin{abstract}
A determinant program over the finite field of order \(11^3 = 1331\) spends nearly all of its time in polynomial arithmetic on individual field elements.
This paper stores each field element as an integer index and precomputes every sum, product, negation, and reciprocal in arrays indexed by that integer.
The public interface, header paths, and type names are unchanged, so the driver and the matrix library switch between the original and cached arithmetic by changing one CMake dependency.
On one thread of an AMD Ryzen 9 7900X, a \(256 \times 256\) run drops from 9.35\,s to 0.87\,s, and a \(512 \times 512\) run drops from 78.8\,s to 2.99\,s.
Building the tables takes about 0.54\,s, so at \(n = 64\) the cached total is still slower.
Peak memory stays close to the original field once the matrices dominate: 25\,MB against 18\,MB at \(n = 256\), and 66\,MB against 59\,MB at \(n = 512\).
The determinant is then distributed with a blocked PLU factorization over MPI, and each exchanged value is that same index.
On a four-machine cluster with eight ranks and block size 32, one determinant ties the sequential time at \(n = 512\), is faster at \(n = 768\), and is 1.6 times faster at \(n = 2048\), 22.96\,s against 36.05\,s.
\end{abstract}
